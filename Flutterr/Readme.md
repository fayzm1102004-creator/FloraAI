# FloraAI - Mobile Application

This is the frontend component of the FloraAI project, built using Flutter. It provides an intuitive interface for users to take pictures of their plants, communicate with our backend API, and receive AI-powered diagnoses.

## Features

* **User Authentication**: Secure login and registration.
* **Image Capture**: Upload or capture plant leaf images directly from the device camera.
* **Diagnosis History**: View past plant health reports.
* **Seamless API Integration**: Communicates with the .NET backend for data processing and history management.

## Prerequisites

* [Flutter SDK](https://flutter.dev/docs/get-started/install)
* Android Studio or Xcode (for iOS development)
* A running instance of the FloraAI backend API.

## Getting Started

1. **Install Dependencies**:
   Run the following command in your terminal:
   `flutter pub get`

2. **Environment Configuration**:
   Ensure the API base URLs in your service files point to your local or deployed .NET backend instance.

3. **Run the App**:
   Connect a physical device or start an emulator, then run:
   `flutter run`
